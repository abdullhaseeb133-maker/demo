Deploy using Netlify Git-based build or Netlify CLI (not simple drag-and-drop, because server functions must be built). Configure LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET, LIVEKIT_AGENT_NAME as server environment variables. Agent name must be its dispatch name, not agent ID. Redeploy and test. Public token endpoint permits public calls; add rate limiting before public distribution. Cloud usage may incur charges. Never put API secrets in HTML. Integration not live-tested.
